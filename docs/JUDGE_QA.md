# Likely Jury Questions\n\n### Why not a generic chatbot?\nThe output is constrained: source-grounded steps, catalog-only actionable URIs, structured JSON, and final validation.\n\n### Where is the LLM?\nThe default benchmark is deterministic and offline. An optional OpenAI-compatible adapter exists behind the enrichment boundary.\n\n### How do you prevent hallucinated URLs?\nEvery actionable deeplink must exist in the supplied catalog; arbitrary HTTP URLs are rejected.\n\n### How does it scale?\nThe mapping and retrieval layers are separated from the API contract. Production can replace TF-IDF with dense embeddings and ANN, plus distributed caching.\n\n### Main limitation?\nThe prototype uses the supplied starter corpus. Production needs larger evaluation labels, stronger intent modeling, and device-level Settings handoff.\n
