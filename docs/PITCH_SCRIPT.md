# RootCause — Jury Pitch\n\nCustomers describe symptoms, not Settings paths. RootCause translates that vague complaint into a validated plan.\n\nWe enrich the query, retrieve the relevant SIIS guidance, structure operational steps, map actionable steps to exact catalog deeplinks, and cache validated results.\n\nThe shipped demo is deterministic and offline for reproducibility. Retrieval uses word and character TF-IDF with fuzzy reranking. An optional LLM adapter is isolated behind the enrichment boundary.\n\nAcross the 20 supplied starter cases, the prototype enforces the response contract, blocks HTTP URL leaks, and gates actionable deeplinks against the supplied catalog.\n\nRootCause is a grounded action planner: vague complaint in, validated troubleshooting plan out.\n
